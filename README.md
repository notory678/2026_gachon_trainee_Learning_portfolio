# 📚 KakaoCloud Certified Essentials 학습 가이드

본 러닝 포트폴리오는 KakaoCloud Certified Essentials (Exam Blueprint v1.0)를 기준으로 제작되었습니다. 모든 콘텐츠는 KakaoCloud 공식 기술 문서를 근거로 구성되었으며, 응시자들이 방대한 기술 문서 속에서 핵심을 파악하고 실전 대응력을 높일 수 있도록 설계된 학습 보조 자료입니다 .

---

### 💡 주요 구성 및 학습 포인트

* 핵심 개념 정의 : 시험 범위 내 필수 개념을 전달합니다.
  
* 개념 비교 및 핵심 요약 : 혼동하기 쉬운 기술 간 차이점을 분석하고, "🚨오개념"항목에서 개념오류가 높은 포인트를 짚어 학습자 학습을 돕습니다.
  
* 시나리오 flow : 단순 이론 학습을 넘어 서비스 흐름을 생각 해보도록 유도 합니다.
  
* 문항 아이디어 (Quiz) : 공식 문서 탐색을 유도하는 실전 난이도의 문항을 통해, 문제 해결 능력을 증진 시킵니다.

---

### 🔗 공식 문서 연계 활용법

각 항목에는 심도 있는 학습을 원하는 분들을 위해 관련 기술 문서 링크([파란색 텍스트](https://docs.kakaocloud.com/))를 포함하였습니다. 기본 배경지식부터 상세한 설정 방법까지 긴밀하게 연결되어 있으니, 링크를 통해 공식 문서의 구조와 세부 내용을 함께 숙지하시길 권장합니다.

> Note : 본 자료는 학습을 돕는 보조 자료이며, 가장 정확하고 최신화된 정보는 항상 [KakaoCloud 공식 기술 문서](https://docs.kakaocloud.com)에서 확인하실 수 있습니다.
